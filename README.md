# CryptoLabX

## Project Description

CryptoLabX is a modular cryptography and cryptanalysis toolkit developed as part of the Cryptography Laboratory course. This project serves as the foundation for implementing classical cryptographic algorithms, modern cryptography techniques, cryptanalysis attacks, and statistical analysis in future assignments.

## Current Features

- Menu-driven command-line interface
- Encrypt, Decrypt, Attack and Analyze menu options
- Text file analysis
- Character count
- Word count
- Line count
- Unique character count
- Letter frequency analysis
- Execution logging
- Git version control
